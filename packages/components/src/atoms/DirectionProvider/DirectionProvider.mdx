<VisuallyHidden asChild><h2>Intro</h2></VisuallyHidden>

<ComponentHeader title="DirectionProvider" tier="Atom" />

Says which way the app reads, once, near the root. A direction-aware component that is given no `dir` of its
own uses the nearest provider's direction, so a right-to-left app wraps its root instead of passing `dir` to
every `Sidebar`, `Navbar` and part. It renders no element and changes no style; the layout itself follows the
`dir` attribute of the page, which `AppShell` sets for you. Today `AppShell`, `Sidebar`, `Navbar`, `Slider`, `RangeSlider`, `ScrollArea`, `ToggleGroup`, `Stepper`, `Combobox`,
`MultiSelect`, `Tree` and `CommandPalette` read it; the other direction-aware components still take `dir` on their own and will follow.

### Import

```tsx
import { DirectionProvider, useDirection } from "@dbm-system/components";
```

## Usage guidelines

<div className="dbm-do-dont-grid">
<Callout tone="success" title="Do">

- Wrap the app once, as high as the direction is known (the user's language setting).
- Also set `dir` on the page (`<html dir="rtl">`), or use `AppShell`, which sets both.
- Give a component its own `dir` only for an island that reads the other way.

</Callout>
<Callout tone="danger" title="Don't">

- Don't expect the provider to flip the layout: it carries a value, not a style.
- Don't nest a provider to change the direction of a single component; give that component a `dir`.

</Callout>
</div>

## Best practices

- Read the direction in your own parts with `useDirection()` rather than checking the document.
- Nothing is detected: the provider says what the app tells it.

## Accessibility

<Callout tone="info" title="The provider adds nothing to the accessibility tree">

It renders no element. The page's `dir` and `lang` are what assistive technology reads; keep them in step
with the provider's value.

</Callout>

## Code examples

```tsx
<DirectionProvider dir="rtl">
  <Navbar>
    <Navbar.Brand href="/">أكمي</Navbar.Brand>
  </Navbar>
</DirectionProvider>
```

## Design tokens used

`DirectionProvider` references **no tokens**: it renders nothing of its own.
