# Icons

DBM draws icons from [Phosphor](https://phosphoricons.com), re-exported by `@dbm-system/icons`. Import
an icon by name and pass the **component**, not a string, to `Icon` (or to the `icon` prop of
`Button`, `IconButton`, `Menu.Item` and the other components that take one). Unused icons are dropped
from the bundle, and a wrong name is a type error.

```tsx
import { Icon } from "@dbm-system/components";
import { WalletIcon } from "@dbm-system/icons";

<Icon icon={WalletIcon} size="lg" tone="brand" label="Wallet" />
```

## Weights

Every icon comes in six weights: `thin`, `light`, `regular`, `bold`, `fill` and `duotone`. Pass one
with the `weight` prop of `Icon`. DBM's default is `bold`, which is what the components draw their own
icons at. Below are the 35 icons the components import most, most used first; choose a weight to
see them all in it, and press an icon to copy its import line. Names end in `Icon`, which is the form
DBM code uses.

<IconGallery />

Phosphor has well over a thousand more. The button below the grid opens its full, searchable set in
a new tab; whichever you pick, import it by name from `@dbm-system/icons`.

## Properties

`Icon` also accepts any other native `<svg>` attribute beyond what is listed here (such as `onClick`
or `title`), passed straight through to the underlying element.

## Usage guidelines

<div className="dbm-do-dont-grid">
<Callout tone="success" title="Do">

- Import the icons you use, by name, from `@dbm-system/icons`.
- Put a `label` on an icon that carries meaning on its own, and leave it off when text next to it
  already says the same thing.
- Give an icon-only button an `aria-label`, since the icon inside it is decorative.
- Pick a `tone` so the icon follows the theme, or leave it unset to inherit the text colour around it.
- Keep to the default `bold` weight unless there is a named reason to change it, such as a `duotone`
  illustration or a `fill` state for a selected item.

</Callout>
<Callout tone="danger" title="Don't">

- Don't pass a string icon name. `icon` is always a component.
- Don't import the whole icon set into a bundle you ship.
- Don't use an icon as the only signal of a state. Add text or a shape as well.
- Don't set a colour on an icon by hand with `style`. Use `tone`.
- Don't mix weights in one row of icons without a reason. Mixed stroke weights read as a mistake.

</Callout>
</div>
