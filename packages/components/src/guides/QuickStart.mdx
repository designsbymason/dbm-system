# Quick start

This builds a small settings card with Vite and React. Every step here is the same in any React app;
[Frameworks](?path=/docs/getting-started-frameworks--docs) covers the differences in Next.js and Astro.

## 1. Create the app

```bash
pnpm create vite my-app --template react-ts
cd my-app
pnpm install
```

## 2. Add DBM System

```bash
pnpm add @dbm-system/components @dbm-system/tokens @dbm-system/icons
```

## 3. Import the stylesheet and a theme

At the top of `src/main.tsx`:

```tsx
import "@dbm-system/components/styles.css";
import "@dbm-system/tokens/css/purple-light.bundled.css";
```

Vite's starter also imports its own `index.css`, which sets colours and fonts of its own. Remove that import so
the theme's tokens are what you see.

## 4. Choose the theme and load the fonts

In `index.html`, set the theme on the root element and load Nunito and Lora:

```html
<html lang="en" data-theme="purple-light">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <link rel="preconnect" href="https://fonts.googleapis.com" />
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
    <link
      href="https://fonts.googleapis.com/css2?family=Lora:wght@400;500;600;700&family=Nunito:wght@400;500;600;700&display=swap"
      rel="stylesheet"
    />
    <title>My app</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```

## 5. Build something

Replace `src/App.tsx`:

```tsx
import { Button, Card, FormField, Input, Switch } from "@dbm-system/components";

export default function App() {
  return (
    <main style={{ maxWidth: "28rem", margin: "var(--dbm-space-12) auto", padding: "0 var(--dbm-space-4)" }}>
      <Card variant="elevated">
        <Card.Header>Notifications</Card.Header>
        <Card.Body>
          <div style={{ display: "grid", gap: "var(--dbm-space-4)" }}>
            <FormField label="Work email" name="email">
              {(field) => <Input {...field} type="email" placeholder="you@example.com" />}
            </FormField>
            <Switch defaultChecked>Weekly summary</Switch>
          </div>
        </Card.Body>
        <Card.Footer align="end">
          <Button variant="secondary">Cancel</Button>
          <Button>Save changes</Button>
        </Card.Footer>
      </Card>
    </main>
  );
}
```

Spacing comes from the tokens (`var(--dbm-space-4)`), never a literal value, so it follows the theme like
everything else.

Run it:

```bash
pnpm dev
```

## Try the other themes

Change `data-theme` to `purple-dark`, `emerald-light` or `emerald-dark`, and import that theme's bundle instead.
The card changes and the component code doesn't. To let the reader choose, see `ThemeProvider` in the
[Theming guide](?path=/docs/guides-theming--docs).
