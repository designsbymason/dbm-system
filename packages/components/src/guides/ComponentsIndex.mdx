# Index

Every component, with a line on each. The sidebar lists the components alphabetically; here you can search by name, or
filter by tier and category, and a name opens its Docs page. The list is built from this Storybook's own index and the
component catalog, so a new component appears here without an edit to the page. The templates have an Index of their own,
first in Templates.
