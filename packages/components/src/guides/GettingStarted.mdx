# Getting started

Welcome to the DBM System documentation.

DBM System is an agentic React component library for building web and enterprise applications quickly,
consistently and accessibly, with a typed, token-driven API that AI coding agents and developers can both
rely on.

"Agentic" means it is built to be read by AI coding agents as well as people. Every component has full
types, a hand-written snippet for each example, and checks for accessibility, responsive layout and
right-to-left text. It is built on a small set of design tokens, so the same components carry two brands,
**Purple** and **Emerald**, each in light and dark. It depends on very little: only Radix UI primitives
for interaction and Phosphor for icons.

The sections below run from installing the library, through the guides and the tokens behind it, to the
components themselves.

## Installation

<Callout tone="info" title="In active development, not yet published">

The package is not on npm yet. These are the steps for when it is, and they are checked on every
change against the packed packages installed into an empty app.

</Callout>

Install the components and the tokens (React 18 or newer is a peer dependency):

```bash
pnpm add @dbm-system/components @dbm-system/tokens
```

Import the stylesheet and one theme once, in your app's entry, and choose the theme on the root element:

```ts
import "@dbm-system/components/styles.css";
import "@dbm-system/tokens/css/purple-light.bundled.css";
```

```html
<html data-theme="purple-light">
```

The themes are `purple-light`, `purple-dark`, `emerald-light` and `emerald-dark`. The package ships no
fonts: load `Nunito` and `Lora` from Google Fonts or host them yourself, or the browser's fallback fonts
are used. The package README has the `<link>` and `@font-face` snippets, and the Theming guide covers
switching themes at runtime.

## For AI agents

<Callout tone="info" title="In active development, not yet published">

The package ships a machine-readable manifest of every component, its props and parts, and every hook and
function: `@dbm-system/components/manifest/index.json` lists them, with one file per component beside it.
Every component page here has full types and a snippet for each example. A usage guide written for coding
agents and an MCP server are planned.
