# Getting started

Welcome to the DBM System documentation.

DBM System is an agentic React component library for building web and enterprise applications quickly,
consistently and accessibly, with a typed, token-driven API that AI coding agents and developers can both
rely on.

"Agentic" means it is built to be read by AI coding agents as well as people. Every component has full
types, a hand-written snippet for each example, and checks for accessibility, responsive layout and
right-to-left text. It is built on a small set of design tokens, so the same components carry two brands,
**Purple** and **Emerald**, each in light and dark. It depends on very little: only Radix UI primitives
for interaction and Phosphor for icons.

The sections below run from installing the library, through the guides and the tokens behind it, to the
components themselves.
