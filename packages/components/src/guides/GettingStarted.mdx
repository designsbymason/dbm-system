# Getting started

Welcome to the DBM System documentation.

DBM System is an agentic React component library for building web and enterprise applications quickly,
consistently and accessibly, with a typed, token-driven API that AI coding agents and developers can both
rely on.

"Agentic" means it is built to be read by AI coding agents as well as people. Every component has full
types, a hand-written snippet for each example, and checks for accessibility, responsive layout and
right-to-left text. It is built on a small set of design tokens, so the same components carry two brands,
**Purple** and **Emerald**, each in light and dark. It depends on very little: only Radix UI primitives
for interaction and Phosphor for icons.

The sections below run from installing the library, through the guides and the tokens behind it, to the
components themselves.

## Installation

The packages are on npm at `0.1.x`, and the API is pre-1.0: a breaking change before `1.0.0` bumps the minor
version and says how to migrate in its changelog, which is on each [GitHub release](https://github.com/designsbymason/dbm-system/releases).
These steps are checked on every change against the packed packages installed into an empty app.

**What you need:** React 18 or newer (a peer dependency), and a bundler that can import CSS (Vite, webpack and
esbuild all can).

**1. Install** the components, the tokens (the theme CSS) and the icons:

```bash
pnpm add @dbm-system/components @dbm-system/tokens @dbm-system/icons
```

**2. Import** the stylesheet and one theme once, in your app's entry:

```ts
import "@dbm-system/components/styles.css";
import "@dbm-system/tokens/css/purple-light.bundled.css";
```

**3. Choose the theme** on the root element:

```html
<html data-theme="purple-light">
```

The themes are `purple-light`, `purple-dark`, `emerald-light` and `emerald-dark`. The Theming guide covers
switching between them at runtime, with `ThemeProvider`.

**4. Load the fonts.** The package ships no fonts. The components use `Nunito` and `Lora`; without them the
browser's fallback fonts are used. Load them from Google Fonts, in your page's `<head>`:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link
  href="https://fonts.googleapis.com/css2?family=Lora:wght@400;500;600;700&family=Nunito:wght@400;500;600;700&display=swap"
  rel="stylesheet"
/>
```

or host them yourself: the package README has the `@font-face` declarations.

**5. Use a component.**

```tsx
import { Button } from "@dbm-system/components";

export function Example() {
  return <Button>Save</Button>;
}
```

Style with the tokens, never with literal values: `var(--dbm-bg-brand)`, `var(--dbm-space-4)`. The Foundations pages
below list every token, and the components work the same under server rendering and in the browser.

Found a problem or have an idea? [Open an issue](https://github.com/designsbymason/dbm-system/issues). If DBM System is
useful to you, a star on [GitHub](https://github.com/designsbymason/dbm-system) is the best way to support it.
