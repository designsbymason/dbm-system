# Components

Every DBM component in one place. Each name opens its Docs page, which has the live Playground, the
props, usage guidance, accessibility notes and a copyable snippet for every example. Components are
built in three tiers: an **atom** is a single building block (a `Button`, an `Input`), a **molecule**
combines a few atoms into one working unit (a `FormField`, a `Select`), and an **organism** is a
complete pattern (a `DataTable`, a `Dialog`). Find one by name, or narrow the list by tier and by
category. The list is read from Storybook itself, so it always matches the sidebar.
