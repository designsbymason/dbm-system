# Index

Every template, with a line on each: the application shells an app is built in, which are template-level components and ship in
the package, and the example pages an app copies. A name opens its Docs page; the shells' pages are in Components, and an
asterisk marks them. The list is built from this Storybook's own index, so a new template appears here without an edit to the
page. The components have an Index of their own, first in Components, which lists the shells too.
