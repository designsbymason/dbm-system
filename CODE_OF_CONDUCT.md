# Code of conduct

This project is a place for people to talk about building accessible interfaces. Be respectful.

## Expected

- Be kind and assume good faith. Disagree with the idea, not the person.
- Keep issues and comments on topic, specific and constructive.
- Respect that this is a solo-maintained project with limited time.

## Not accepted

- Harassment, insults, discrimination or personal attacks of any kind.
- Publishing someone else's private information.
- Spam, advertising, or repeated demands for a response.

## Enforcement

The maintainer may edit or remove comments, close or lock issues and pull requests, and block people from the repository when conduct falls short of this. To report a problem, use the private reporting form described in [SECURITY.md](./SECURITY.md) and say that it is a conduct report, or contact the maintainer through their GitHub profile.

This applies to the repository, its issues and pull requests, and the Storybook and docs site.
