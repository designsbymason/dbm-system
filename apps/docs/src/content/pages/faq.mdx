## Is it free to use?

Yes. The code and these docs are MIT licensed, for personal and commercial work. The fonts it uses, Nunito and Lora, are under the SIL Open Font License.

## Is it ready for production?

The packages are published and every component is reviewed and tested, but the API is pre-1.0: a release before `1.0.0` can include breaking changes. When one does, the version's minor number goes up and its changelog says how to migrate.

## Which React versions does it support?

React 18 and later.

## Does it work with server rendering?

Yes. Every component renders on the server without touching browser-only APIs. In the Next.js App Router, use the components from a file marked `"use client"`. [Frameworks](/docs/frameworks) has the details.

## How big is it?

An app ships only the components it imports: each component is its own module, so a bundler leaves the rest out. `Button` alone is about 3 KB of gzipped JavaScript, besides React. The stylesheet is one file for every component.

## Can I use my own brand?

Every component reads semantic tokens, so a brand is a set of token values. Two brands ship today, Purple and Emerald, each in light and dark. A theme of your own is a file that sets the same semantic tokens.

## Do I have to use Tailwind or a CSS-in-JS library?

No. The components are styled with CSS Modules and CSS custom properties, and ship one stylesheet. Use whatever you like for your own code, and read the tokens with `var(--dbm-…)`.

## Does it support right-to-left languages?

Yes. Every component works in both directions; set `dir="rtl"` on the page or a section, or use `DirectionProvider`.

## What does "agentic" mean here?

That the library is made to be read by AI coding agents as well as people: a typed manifest of every component and prop, a guide for agents, and every docs page as Markdown. See [AI agents](/agents).

## Where do I report a bug or ask for something?

On [GitHub Issues](https://github.com/designsbymason/dbm-system/issues). Security problems go through the private reporting described in the repository's security policy.
