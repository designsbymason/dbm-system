title: Installation

---

These steps are checked on every change: the packed packages are installed into an empty app, bundled with esbuild and with webpack, and a component is checked in a browser in light and dark.

**What you need:** React 18 or newer, and a bundler that can import CSS. Vite, webpack, esbuild and the frameworks built on them all can.

## 1. Install the packages

The components, the tokens (your app imports a theme from them) and the icons:

```bash
pnpm add @dbm-system/components @dbm-system/tokens @dbm-system/icons
```

With npm, `npm install`; with yarn or bun, `yarn add` or `bun add`, and the same three packages.

## 2. Import the stylesheet and a theme

Once, in your app's entry:

```ts
import "@dbm-system/components/styles.css";
import "@dbm-system/tokens/css/purple-light.bundled.css";
```

`styles.css` holds every component's CSS. Each bundled theme file holds the primitives, the component tokens and that theme's semantic tokens:

| Theme | File |
|---|---|
| Purple, light | `purple-light.bundled.css` |
| Purple, dark | `purple-dark.bundled.css` |
| Emerald, light | `emerald-light.bundled.css` |
| Emerald, dark | `emerald-dark.bundled.css` |

## 3. Choose the theme

Set it on the root element, so the first paint is already themed:

```html
<html data-theme="purple-light">
```

To switch at runtime, import every theme you offer and change the attribute, or wrap the app in `ThemeProvider` (`brand="purple" mode="system"`), which sets it for you and can follow the system's light or dark setting.

### Offering more than one theme

Each bundled file repeats the primitives and the component tokens. That is harmless, but to avoid it, import the shared files once and one file per theme:

```ts
import "@dbm-system/tokens/css/primitives.css";
import "@dbm-system/tokens/css/component-tokens.css";
import "@dbm-system/tokens/css/purple-light.css";
import "@dbm-system/tokens/css/purple-dark.css";
```

## 4. Load the fonts

The components use Nunito (the interface) and Lora (editorial text). The package ships no fonts; without them the browser's fallback fonts are used. Load them from Google Fonts, in your page's head:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link
  href="https://fonts.googleapis.com/css2?family=Lora:wght@400;500;600;700&family=Nunito:wght@400;500;600;700&display=swap"
  rel="stylesheet"
/>
```

Or host them yourself: both are open source (SIL Open Font License). Download the variable `.woff2` files and declare them:

```css
@font-face {
  font-family: "Nunito";
  font-style: normal;
  font-weight: 400 700;
  font-display: swap;
  src: url("/fonts/nunito-variable.woff2") format("woff2");
}

@font-face {
  font-family: "Lora";
  font-style: normal;
  font-weight: 400 700;
  font-display: swap;
  src: url("/fonts/lora-variable.woff2") format("woff2");
}
```

## 5. Use a component

```tsx
import { Button } from "@dbm-system/components";

export function Example() {
  return <Button>Save</Button>;
}
```

Style your own code with the tokens, never with literal values: `var(--dbm-bg-brand)`, `var(--dbm-space-4)`.
