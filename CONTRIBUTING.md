# Contributing

DBM System is a solo-maintained project. The repository is public and the published packages are MIT licensed, so you're welcome to use, fork, and modify the code under the terms of that license.

## Issues

Issues are open. Use the templates for a bug, a feature request or a documentation problem. A good report names the component, says what you expected and what happened, and links to the Storybook story where it shows. There is no response or fix timeline. Report a security vulnerability privately instead; see [SECURITY.md](./SECURITY.md).

## Pull requests

**Pull requests are limited to collaborators, by invitation, for now** ([ADR-0172](./guidelines/adr/0172-pull-requests-are-enabled-for-collaborators-only-and-issues-are-on-over-keeping-both-off-or-opening-contributions-to-everyone.md)). If you would like to change something, open an issue first so it can be discussed; forking under the MIT license is always open to you. Opening pull requests to everyone may come later, with a contribution policy.

## Conduct

Everyone taking part follows the [code of conduct](./CODE_OF_CONDUCT.md).

## Working on the code

Start with `CLAUDE.md` and the numbered documents in `guidelines/`. Turn on the pre-commit guard once per clone with `git config core.hooksPath .githooks`.
